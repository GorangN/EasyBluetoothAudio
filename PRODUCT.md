# EasyBluetoothAudio

## Platform

Web marketing surface for a native Windows application.

## Stack

Astro static output, React islands for Magic UI, GitHub Actions deployment to GitHub Pages. Explicitly requested by the user.

## Users and purpose

People with a Windows PC and a paired phone who want phone media to play through the PC's speakers or headphones. The main action is downloading the free x64 installer from GitHub Releases.

## Evidence and constraints

README.md, .agents/product-marketing.md, LICENSE, the native source, and release v1.3.1 establish the product claims. Windows 10 version 2004/build 19041 or later, Windows 11, x64, and working Bluetooth are required. The .NET runtime is bundled. Media playback is supported; universal device compatibility, calls, latency guarantees, and customer testimonials are not established.

## Brand

Preserve the native app's charcoal and acid-yellow identity. Use direct, friendly language grounded in the listening outcome. The existing GIF shows an older interface; a labeled interface preview can reflect current controls without pretending to be a screenshot.

## Decisions delegated by the user

The user explicitly requested autonomous decisions without a clarification round. Audience segmentation and conversion strategy are editorial assumptions, not research results. Use observable GitHub community evidence and source transparency for trust. No analytics or email collection are needed for a direct-download page.
